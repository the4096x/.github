# 4096x

**[4096x.com](https://4096x.com)** is a collection of merge numbers games you play in the browser, on phone or computer.

Every game has the same goal: merge twin numbers until you build **4096**. The "x" is the variety: each game plays a different way, from sliding and stacking to shooting, turning and placing.

- 78+ games, with new ones added often
- No download, no sign-up
- Works on phones, tablets and computers

A few to start with: [4096 Classic](https://4096x.com/classic/), [4096 Drop](https://4096x.com/drop/), [4096 Snake](https://4096x.com/snake/), [4096 Bubble](https://4096x.com/bubble/), [4096 Knight](https://4096x.com/knight/).
